# Contributing to TalhaGPT

Thanks for your interest in TalhaGPT.

## Development

1. Fork the repository.
2. Create a feature branch.
3. Install the dependencies from `requirements.txt`.
4. Make your changes.
5. Run the test suite with `pytest`.
6. Open a pull request with a clear description of the change.

## Guidelines

- Keep changes focused and easy to review.
- Prefer small, testable modules.
- Do not commit API keys, tokens, passwords, or private data.
- Add or update tests when changing core behavior.
- Keep tool permissions and local-system access conservative.
- Document user-visible features in the README when appropriate.

## Bug reports

Include:

- What you expected to happen.
- What actually happened.
- Steps to reproduce it.
- Relevant error output.
- Python, Ollama, and model versions when relevant.
